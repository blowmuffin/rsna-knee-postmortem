# Is heliosli's SKM-TEA/KneeXNet anatomy model allowed in a final submission?
750258 | Karan Bhatti (@sircausticmail) | 2026-10-17T13:40 | votes -20

heliosli/rsna-orthofoundation-fold0-epoch7-20261004 is in about 70% of the public notebooks at 0.95+ (about a quarter of those at 0.90+). Its page says it holds "unchanged SKM-TEA/KneeXNet auxiliary weights" and that "no new open-source license is granted". The file anatomy.pt finds the knee in each test scan, and the R6, R7 and S6 ConvNeXt models then read crops placed by it.

- SKM-TEA (Stanford AIMI) needs registration and acceptance of data-use terms.

- KneeXNet is built from OAI images and has no licence we could find.

Questions:

- Can a final submission use a model trained on SKM-TEA?

- Can it use one trained on KneeXNet?

- These weights come with no licence. Can a winner still use them, given the CC BY-NC 4.0 winner licence?

A yes or no for each is enough. Most top public notebooks attach this dataset, so the answer matters to many teams. Thank you.
