# Efficiency Prize: are GPU notebooks eligible, and what does RuntimeSeconds cover?
733475 | epicfangs | 2026-08-07T02:36 | votes 0

Two questions about the Efficiency Prize, both of which change how a submission would be built.

- Are GPU notebooks eligible for the Efficiency Prize, or is that track CPU-only? The Code Requirements allow either a CPU or a GPU notebook up to 9 hours for the competition generally, but the Efficiency Prize Evaluation section doesn't say whether the second track narrows that.

- What does RuntimeSeconds actually cover? The Overview describes it as "the number of seconds it takes for the submission to be evaluated". Is that the full wall time of the rerun notebook — including package installation, model loading and reading the test DICOMs — or only an inner scoring portion?

Both matter quite a bit here because the DICOM read and decode path is CPU-bound, so whether a GPU is available at all, and whether setup time is counted, point at fairly different designs.

Thanks!
